# COVID-19 Analysis and Data Science Projects

A comprehensive collection of data analytics projects in Python, with a focus on COVID-19 pandemic analysis and various other data science applications.

## 📊 Featured Projects

### 1. COVID-19 Pandemic Analysis
**Directory:** `covid19-pandemic-analysis/`

Comprehensive analysis of the COVID-19 pandemic using data from Johns Hopkins CSSE COVID-19 repository.

**Features:**
- **Data Processing Scripts:** Automated data wrangling and feature engineering
- **Time Series Analysis:** Cases, deaths, and recovery data over time
- **Geographic Analysis:** Country and continent-level breakdowns
- **Mortality Analysis:** Death rates and demographic correlations
- **Socioeconomic Impact:** GDP and population density correlations
- **Interactive Visualizations:** Comprehensive plotting and data visualization

**Key Files:**
- `notebooks/` - Jupyter notebooks for exploratory data analysis
- `features/` - Data processing and feature engineering scripts
- `visualizations/` - COVID-19 data visualization tools
- `data/raw/COVID-19/` - Johns Hopkins CSSE COVID-19 data repository

**Dependencies:** pandas, numpy, matplotlib, seaborn, plotly, scipy

### 2. Cracow Real Estate Pricing Analysis
**Directory:** `cracow-real-estate-pricing/`

Machine learning analysis of real estate prices in Cracow, Poland.

**Features:**
- Data wrangling and cleaning of property listings
- Exploratory data analysis of pricing factors
- Predictive modeling for property valuations
- District-wise price analysis
- Feature importance analysis (area, location, amenities)

### 3. FX Trading Results Analysis
**Directory:** `fx-trading-analysis/`

Statistical analysis of foreign exchange trading performance.

**Features:**
- Trading performance metrics calculation
- Risk analysis and drawdown calculations
- Profit/loss distribution analysis
- Probability modeling for trading outcomes

### 4. Global Terrorism Database EDA
**Directory:** `global-terrorism-eda/`

Exploratory data analysis of global terrorism incidents.

**Features:**
- Temporal analysis of terrorism trends
- Geographic distribution of incidents
- Attack methods and target analysis
- Casualty analysis by region and time

### 5. Polar Watch Fitness Analysis
**Directory:** `polar-watch-fitness-analysis/`

Analysis of fitness data from Polar watch devices.

**Features:**
- Workout pattern analysis
- Heart rate and calorie correlation studies
- Exercise intensity modeling
- Predictive modeling for fitness metrics

## 🛠️ Technologies Used

- **Python 3.x**
- **Data Analysis:** pandas, numpy, scipy
- **Visualization:** matplotlib, seaborn, plotly
- **Machine Learning:** scikit-learn
- **Jupyter Notebooks** for interactive analysis
- **Git** for version control

## 📈 Data Sources

- **COVID-19 Data:** Johns Hopkins CSSE COVID-19 Data Repository
- **World Bank Data:** GDP, population, and urbanization statistics
- **Geographic Data:** Country coordinates and continent mappings
- **Real Estate Data:** Property listings from Cracow market
- **Financial Data:** FX trading transaction records
- **Terrorism Data:** Global Terrorism Database
- **Fitness Data:** Polar device workout exports

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Tech-anurag95/Covid-19-Analysis.git
   cd Covid-19-Analysis
   ```

2. **Install dependencies:**
   ```bash
   pip install -r covid19-pandemic-analysis/requirements.txt
   # Or for specific projects:
   pip install -r cracow-real-estate-pricing/requirements.txt
   pip install -r fx-trading-analysis/requirements.txt
   # etc.
   ```

3. **Run analysis:**
   Navigate to any project directory and open the Jupyter notebooks:
   ```bash
   cd covid19-pandemic-analysis/notebooks/
   jupyter notebook
   ```
